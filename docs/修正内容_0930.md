## コードでは直せない・まだやっていないこと
1. **本番の二要素認証**：本番が `MAIL_DRIVER=log` のためワンタイムコードが画面に出る。Resend の API キーを設定して `MAIL_DRIVER=resend` にする必要あり。あわせて本番の初期パスワード（公開リポジトリに書いてある pass1234 など）を変更すること
2. **商品写真の保存先**：Railway の web サービスに Volume が無いので、再デプロイで写真が消える。Volume（マウント先 `/var/www/html/img/product`）の追加が必要
3. **納品予定日**：要件「いつ納品されるのか一目でわかるように」に対応する項目がテーブル定義書に無い。t_order（または明細）に納品予定日を追加するかは設計判断が必要
4. **在庫不足の警告**：発注点（適正在庫）の列がテーブル定義書に無いため、「在庫0以下」以外の警告はできない
5. 棚卸・売上確定の「完全な 1 トランザクション化」は slip.php の関数の作りを変える必要があるので見送り（事前チェックと途中停止で代替）
6. 初期データ（sql/02）の JAN はチェックデジットが合わないダミー値。値を変えない保存だけは通すようにしてある
