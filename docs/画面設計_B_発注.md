# 画面設計（担当B：発注）お手本　コマ3

紙に書くときもこの項目立て（画面ID・ファイル・権限／入力項目／表示項目／ボタンと遷移／注意）で書く。

## SC-10 発注入力　order/order_input.php　（権限：ログイン済）

### 入力項目
| 項目 | name | 型 | 必須 | 初期値 | チェック |
|---|---|---|---|---|---|
| 発注日 | order_date | date | ○ | 今日 | 日付として正しい |
| 商品コード（複数行） | product_code[] | text | 数量がある行は○ | 空 | m_product に存在し is_deleted=0 |
| 数量 | order_qty[] | number | 商品コードがある行は○ | 空 | 整数・**0不可**・マイナス可 |
| 取消元の発注明細（マイナス行のみ） | ref_order_no[] / ref_line_no[]（hidden。選択はプルダウン） | select | マイナス行は○ | 未選択 | 同じ商品の確定済み・未納品の明細であること（質問No.3） |
| 発注時メモ | memo[] | text | | 空 | 200文字以内 |

### 表示項目（商品コード入力で自動表示）
商品名・規格・入数・契約単価・卸業者名・保存区分バッジ（冷蔵/冷凍）、金額＝契約単価×数量、合計

### ボタンと遷移
| ボタン | 動作 | 遷移先 |
|---|---|---|
| ＋行追加 | 空の明細行を1行追加（JS） | 同画面 |
| 登録 | 卸業者ごとに t_order を1行ずつ作り、明細を t_order_detail に INSERT（トランザクション） | SC-10（完了メッセージ・連続入力） |
| メニューへ戻る | | SC-01 |

### 注意
- 1回の登録で**卸業者ごとに伝票を分ける**（商品の supplier_code でグループ化）
- 明細には contract_price を m_product からコピーし、amount = contract_price × order_qty を保存
- マイナス行は .qty-minus で赤字

## SC-11 発注確定　order/order_confirm.php　（権限：**発注承認可**のみ）

### 入力項目
| 項目 | name | 型 | 必須 |
|---|---|---|---|
| 確定する伝票 | order_no[] | checkbox | 1件以上 |

### 表示項目
未確定の発注伝票一覧：伝票No・発注日・卸業者・明細（商品・数量）・合計金額・発注先メール有無・状態（.status-unconfirmed）

### ボタンと遷移
| ボタン | 動作 | 遷移先 |
|---|---|---|
| 確定（.btn-danger・confirmSubmit） | 伝票ごとに confirmOrder() → sendOrderMail() | SC-12 発注書 |
| メニューへ戻る | | SC-01 |

### 注意
- requireApprover() を先頭で呼ぶ。メニューにも承認可の人にしかリンクを出さない
- 確定は confirmOrder() だけ。UPDATE文を自分で書かない
- メール送信失敗・発注先メール未登録は setFlash('warning', …)。確定は取り消さない

## SC-12 発注書　order/order_print.php　（PDF帳票）

| 区分 | 内容 |
|---|---|
| 入力 | ?order_no=X |
| 上部 | 発注書（タイトル）・宛先（卸業者名 御中）・卸業者コード・発注日・伝票No・発注元（店名） |
| 明細 | 商品コード・商品名・規格・入数・数量・契約単価・納品金額・発注時メモ ／ 合計 |
| 画面側 | メール送信状況（送信日時 mailed_at／未送信）と「再送」ボタン、「検品一覧表へ」ボタン |
| 遷移 | 検品一覧表へ → SC-13、戻る → SC-11 |

## SC-13 卸業者別検品一覧表　order/inspection_print.php　（PDF帳票）

| 区分 | 内容 |
|---|---|
| 入力 | ?order_no=X（または発注日） |
| 上部 | 卸業者コード・卸業者名・発注日 |
| 明細 | 商品情報（コード・商品名・規格・入数）・数量・納品金額・発注時メモ・**検品チェック欄（✓）** |
| 遷移 | 戻る → SC-11 |

※ SC-12 と SC-13 は項目がほぼ同じなので、データ取得関数を1つにして2画面で使う
